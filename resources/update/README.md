# Страница обновления

Самостоятельный документ для iframe: `/role/update`. На локальной копии: `http://localhost:8081/role/update`.
Оболочка форума и приложение Flarum не загружаются; ширина ограничена 700 px.

## Где править

- `content.html` — весь текст и порядок блоков. Обычный HTML с комментариями по разделам
- `style.css` — только дополнения для анонса. Общие стили берутся из `../guide/style.less`
- `document.html` — HTML-документ без шапки и подвала форума
- `embed.js` — наследование темы родительского форума и высота собственного iframe
- `../../src/Guide/UpdateController.php` — выдача документа с тем же правом просмотра форума, что у путеводителя

Контроллер подключает готовую сборку CSS форума. Типографика общая с путеводителем:
`../guide/typography.js`. Классы значков подставляются через общий `InterfaceIcons`.
Для значков отдельно подключены штатные локальные Free-шрифты Flarum. Это нужно,
поскольку при настройке CDN/Kit основная сборка содержит пустой шрифт-заглушку,
а самостоятельная страница не загружает приложение и внешнее подключение форума.

## Вставка

```html
<iframe src="/role/update" title="Обновление ролевой"
  style="display:block;width:100%;max-width:700px;height:850px;border:0;margin:0 auto"></iframe>
```

Документ предназначен для вставки на тот же форум. Его высота обновляется по содержимому,
без отдельной прокрутки внутри рамки. Для sandbox нужны `allow-scripts allow-same-origin`;
иначе следует задать высоту iframe вручную. Внешние ссылки на путеводитель используют
`target="_top"` и открывают форум целиком, внутренние якоря остаются в анонсе.
При sandbox также требуется разрешить переход по действию пользователя (`allow-top-navigation-by-user-activation`).

Внутри iframe тема наследуется от родителя. При отдельном открытии используется тема устройства.
Для проверки можно открыть `/role/update?theme=light` или `?theme=dark`.

## Порядок и смысл

Два общих баннера: «Механики» и «Мир и истории». Внутри первого — пять чередующихся
Step / Step--reverse: мастер создания, анкета в профиле, прокачка без проверяющих,
обучение и автоматические проверки. Заголовки шагов имеют кружок с иконкой,
во второй колонке — снимок интерфейса или Note. Затем компактные Facts о навыках
и перках, магии, квестах и наградах. Внутри второго баннера — шаги о пяти годах
после последних событий и Гильдии как центре игры. На узком экране текст каждого
шага идёт перед его изображением или заметкой. Сам мир и существовавшие ранее
кубики не объявляются нововведениями.

В лор добавлена история строительства моста и отдельный шаг о городе Квестпосте
из `content/world.md`. В дополнениях отмечено уже выполненное переименование
«Кузнечного дела» в «Ремесло».

В конце страницы — «План развития», общий Timeline с модификатором `Timeline--roadmap`:
тема с условиями ребута → навык зачарований (рабочее название «Артефакторика») →
крафт предметов. Вместо дат оставлены прочерки в `SectionKicker`: пользователь впишет их сам,
например «середина ноября», без префикса «Срок». Кружки остаются слева от названий,
пункты слегка смещены по горизонтали. Фоновая плавная кривая автоматически
соединяет кружки после изменения текста, дат, ширины или темы.
Это описание будущих этапов, оно не создаёт навык и не включает механику крафта.

`Banner`, `Step`, `Facts`, `Note`, `Figure`, `Badge`, `paper-highlight` используются без копирования их CSS.
Добавлены два варианта: `Hero--update` для афиши и `Section--feature` для цветных глав.
Обёртка `RpUpdate` ограничивает дополнения этой страницей.

## Изображения и цвета

Фоновая иллюстрация пока отсутствует по просьбе пользователя. В дальнейшем её можно задать в
`background-image` у `.RpUpdate .Hero--update`. Две отклонённые иллюстрации не используются.

Акцент главы задаётся через `data-accent`: `water`, `violet`, `ember`, `gold`, `forest`.
Снимки интерфейса используют существующие файлы в `preview/role/assets`.
Для пары снимков сохраните `data-screenshot-theme="light"` и `"dark"`, а также настоящие
`width` и `height`: так тема переключается без схлопывания изображения при загрузке.

## Перед публикацией

- Выбрать фоновую иллюстрацию
- Согласовать текст анонса
- Уточнить условия переноса персонажей и компенсации, затем заменить общее пояснение в последней главе
- При необходимости добавить дату запуска и ссылку на тему с доской квестов

Страница доступна по прямой ссылке на локальном форуме. В меню форума и в объявления она автоматически не добавляется.
После правки HTML достаточно обновить страницу, после CSS — очистить кеш Flarum.
После правки `embed.js` достаточно обновить документ.
