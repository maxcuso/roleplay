# Макет главной страницы /role

Открыть: <http://127.0.0.1:4173/role>.

Стенд запускается обычной командой `npm run preview` из `../../js`. Главная стенда `/` по-прежнему показывает мастер, а `/role` — первые три блока новой страницы. Сервер слушает только локальный адрес и выдаёт файлы по явному списку.

## Где редактировать

| Файл | Что менять |
| --- | --- |
| `index.html` | Заголовок и текст баннера, подписи разделов, оболочку страницы |
| `content.js` | Подписи вкладок, тексты их разделов и список персонажей для слайдера |
| `style.css` | Цвета, ширины, отступы, шрифты и мобильную версию |
| `page.js` | Переключение вкладок, слайдер, тему, демонстрационные окошки |
| `../../resources/presentation/icons.json` | Иконки интерфейса; ключи `landing.*` и существующие общие ключи |

Это отдельный прототип, а не новая копия игровой механики. Компактные плитки «Правила», «Лор» и «Анкета» открывают раздел под ними на той же странице. До первого выбора разделы скрыты. Выбранная вкладка выделяется своим цветом; переключение доступно мышью, стрелками, Home и End. Сейчас разделы содержат краткие тексты для макета; полное содержание подготовим отдельно. Кнопка создания объясняет будущий переход к существующему окошку и позволяет открыть стенд мастера. Настоящие персонажи не создаются.

Четыре героя, их имена, тексты и портреты вымышлены для демонстрации. Для подключения настоящих анкет в `content.js` нужно задать `demo: false` и `link` на выбранную литературную тему.

Слайдер прокручивается стрелками, клавиатурой и свайпом. На широком экране видны три карточки, на телефоне — одна и край следующей. Автоматического перелистывания нет.

Пока тексты главной находятся в HTML и файле примеров. Markdown с лором остаётся в `../../content`; окончательный способ его подключения выбираем при интеграции. Исходные форумные темы при открытии макета не загружаются и не разбираются.

## Иллюстрации

Созданы встроенным ImageGen. Оригиналы сохранены в каталоге generated_images; рабочие копии находятся рядом с макетом:

- `assets/bridge-hero.png` — предыдущий вариант города и гильдии на мосту; больше не используется. Баннер временно имеет однотонный фон `#263744`, заголовок «Текстовая ролевая», описание, пометку «Фэнтези» и две кнопки.
- `assets/character-portraits.png` — четыре демонстрационных портрета в одной иллюстрации. Каждый портрет отображается отдельным фоном средствами CSS; исходная картинка не изменяется.

Промпты сохранены в [image-prompts.md](image-prompts.md).
