# Макет страницы /role

Открыть: <http://127.0.0.1:4173/role>. Простой запуск — двойной клик по `C:\Forum\Flarum\start-role-preview.cmd`; окно сервера нужно оставить работающим.

Другой способ: `npm run preview` из `C:\Forum\Flarum\packages\roleplay-new\js`. На `/` остаётся стенд мастера, на `/role` — страница ролевой. Сервер слушает только локальный адрес и отдаёт файлы по явному списку.

Начните с [EDITING.md](EDITING.md): там размеры, карта CSS, примеры всех компонентов и правила их копирования.

| Файл | Назначение |
| --- | --- |
| `index.html` | Все тексты, оглавления и готовые блоки трёх разделов |
| `style.css` | Палитра, общие компоненты, отдельные элементы страницы и адаптация |
| `content.js` | Подписи вкладок, демонстрационные персонажи и записи характеристик макета |
| `page.js` | Иконки, единое переключение вкладок, галерея, окно и тема |
| `assets/` | Картинки и шрифты |
| `../../resources/presentation/icons.json` | Реестр интерфейсных иконок расширения |

## Структура

Три документа — `panel-rules`, `panel-lore` и `panel-application`. Основные компоненты: `Step`, `Note`, `Banner`, `Facts`, `Figure`, `Grid`, `Tabs`, `Timeline`. Общий текст оформляется внутри `Document`, отступы между главами — через `Section`. `Badge` — значок заголовка, `Table` — рамка с прокруткой для настоящих таблиц.

Частные отличия задаются модификаторами (`Step--reverse`, `Note--compact` и т. п.) и CSS-переменными. Тексты остаются в HTML. Markdown/BBCode-парсер не используется; старые `content/tabs/*.md` сохранены только как исходный материал.

Классы отвечают за оформление, `data-action` и `data-part` — за обработчики. `id` нужны только якорям, подписям и связям доступности вкладок. Переключение поддерживает мышь, стрелки, Home и End; главный раздел запоминается в сессии.

## Данные и изображения

Публичный API справочников пока не подключён. Иконки характеристик берутся из записей макета; значения стоимости сохраняют прочерки. `data-roleplay-block` отмечает места будущих данных. `EntityExample` — временные примеры перков до подключения общих карточек форума.

Четыре героя галереи вымышлены. Настоящая анкета задаётся в `content.js` через `demo: false` и `link`. Галерея поддерживает кнопки, клавиатуру и свайп. Кнопка создания открывает демонстрационное окно со ссылкой на стенд мастера.

`assets/hero-background.jpg` и `assets/locations.jpg` — присланные иллюстрации. Плашки «О ролевой» и «Валюта» используют встроенные SVG. `assets/character-portraits.png` — демонстрационные портреты ImageGen; промпты сохранены в `image-prompts.md`. Старый `bridge-hero.png` больше не используется.

Шрифты Jost, Oracle и Pulp лежат в `assets/fonts/`, форма значка — в `assets/badge-circle.webp`. После добавления новых файлов шрифтов или маршрутов картинок перезапустите сервер.

Автообновление `/events` слушает HTML, CSS и JavaScript только локального макета. Изменения старых Markdown-файлов на страницу не влияют.
