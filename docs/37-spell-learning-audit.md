# Обучение заклинаниям: проверка перед разработкой

Дата: 30 октября 2026 года. Проверены исходный код и действующая локальная база форума. Данные персонажей и справочников при проверке не изменялись.

## Что уже работает

| Часть | Состояние и применение |
| --- | --- |
| Вкладка «Обучение» | Есть в профиле, пока показывает «В разработке» |
| Литература | У предмета есть признак `is_literature`, содержимое книги пока не задаётся |
| Заклинания | Действующий справочник, выбор в мастере, ручная выдача и отображение в анкете |
| Доступный круг | Рассчитывается по приобретённому развитию Магии, без открытия кругов бонусами экипировки |
| Опыт | Есть списание активного опыта с проверкой остатка |
| Операции персонажа | Общие проверки прав, состояния и версии, транзакции, защита от повторной операции |
| История | Общий механизм событий персонажа, пригодный для записи об изучении |
| Карточки | Общие карточки заклинаний и предметов, новые варианты оформления не требуются |
| Редактор предметов | Общий для админки и модераторской, его следует дополнить содержимым литературы |
| JSON | Действующие импорт и экспорт справочников, которые потребуется расширить связями литературы |

`ProgressionTraining.tsx` и тесты с названием learning относятся к развитию навыков и владений. Это не готовая реализация изучения заклинаний из книг.

## Что отсутствует

- Связь предмета литературы с содержащимися в нём знаниями
- Настройка расходования литературы при изучении
- Централизованные цены изучения по кругам
- Выбор доступного обучения по инвентарю персонажа
- Действие игрока «Изучить»: проверка источника, круга, опыта и отсутствия уже изученного заклинания
- Единая операция оплаты, выдачи знания и, при необходимости, расходования единицы источника
- Представление обучения в профиле и запись соответствующего события истории

Таблиц знаний, литературы или обучения в действующей базе не обнаружено. Изученные заклинания уже хранятся в `roleplay_character_spells`, дублировать их отдельным списком владения не требуется.

## Согласованные правила

1. В первом выпуске подключаем только заклинания. Общую основу предусматриваем для заклинаний, рецептов, чертежей и чар
2. Обучение показывает знания только из литературы в инвентаре выбранного персонажа
3. Представление: **общий список заклинаний с указанием книг-источников**, без предварительного выбора книги
4. Изучение мгновенное, без таймера. Стоимость I–V кругов: **5 / 10 / 15 / 20 / 30 активного опыта**, через централизованные настройки
5. Проверяется доступный круг. Дополнительная плата золотом не согласована
6. Книги заклинаний сохраняются. Для другой литературы предусматриваем настройку «Расходуется при изучении»: расходуемый источник содержит ровно одно знание, успешное изучение расходует одну единицу предмета
7. Одно знание может встречаться в нескольких книгах. Потеря книги не удаляет уже изученное знание
8. Сервер повторно проверяет источник, требования и цену. Повторная отправка не должна повторно списывать опыт или выдавать знание
9. В конце работы создаём книгу со всеми стартовыми заклинаниями. **Добавляем только в справочник для ручной выдачи**, стартовые наборы не меняем
10. Уже изученные заклинания во вкладке обучения не показываем: они доступны в анкете. Неизученные, но пока недоступные показываем приглушённо с читаемой причиной недоступности

Для будущих рецептов, чертежей и чар ранее согласованы цены по сложности 5 / 10 / 15 опыта. Их полноценное обучение и изготовление не входят в текущий этап.

## Решение по составу списка

Пользователь уточнил: изученные скрывать, недоступные показывать приглушённо.
У каждого неизученного заклинания остаются книги-источники и стоимость.
При нехватке круга или опыта карточка приглушена, действие изучения недоступно,
причина выводится читаемым текстом рядом с действием. После изучения запись
исчезает из обучения и появляется в обычном списке заклинаний анкеты.

## Основа дальнейшего плана

Это результаты проверки, а не разрешение начать реализацию до обсуждения плана.

- Расширить существующий предмет содержимым литературы, используя ссылки на действующий справочник заклинаний
- Использовать общий механизм операций персонажа и действующее хранение выданных заклинаний
- Подключить редактор, импорт и экспорт вместе, чтобы содержимое книг сохранялось при переносе справочников
- Сделать вкладку обучения на общих карточках с источниками, ценами и понятными причинами недоступности
- Проверить оплату, требования, повторную отправку и изменение источника перед изучением
- Последним шагом создать и проверить новую книгу. Название, описание внешности и окончательные характеристики определить при её наполнении

При подготовке окончательного плана учитывать более поздние договорённости в `development-plan-2026-10-28.md` и `future-development.md`. Старые упоминания книг как задачи за пределами MVP не отражают согласованный состав первого выпуска.

## Дополнение: переключатель «Стартовое»

После проверки добавлено поле заклинания `is_starting` и переключатель «Стартовое»
в общий редактор. Обычный стартовый выбор теперь учитывает этот признак вместе с
I кругом и включённым состоянием заклинания и пути. Существующим записям миграция
сохраняет `true`. Новые записи и старые JSON без поля также получают `true`.
Расовые выдачи и уже полученные заклинания не меняются.

При наполнении будущей книги состав стартовых заклинаний нужно проверить заново
по актуальным данным с учётом `is_starting`, а не использовать все заклинания I круга.

После согласования добавлена [привязка содержимого литературы](38-literature-contents.md):
редактор предмета, типизированные ссылки на заклинания, признак расходования,
JSON-перенос и защита используемых записей. Исходный список отсутствующих частей
выше описывает состояние на момент проверки. Само изучение в профиле ещё не подключено.
