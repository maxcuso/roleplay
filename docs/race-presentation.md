# Справочные поля расы

В редакторе рас диапазон `min_age` / `max_age` называется «Продолжительность жизни».
Ключи оставлены прежними, поэтому существующие JSON-файлы и записи базы совместимы.
Первое число — только справочная информация. Создание и исправление персонажа
проверяют лишь `max_age`; если оно не заполнено, расового ограничения возраста нет.
Возраст по-прежнему должен быть целым неотрицательным числом.

Дополнительные необязательные поля:

- `average_height` — текст до 255 символов, например `170–190 см (обычно)`.
- `distinctive_traits` — многострочный текст до 20 000 символов.
- `background_color` — HEX из шести цифр, например `#AABBCC`. Пустое значение сохраняется как `null`.

Поля предназначены для будущего вывода в правилах. Сейчас они редактируются и
передаются через общий API и импорт/экспорт JSON; отдельный блок правил не создаётся.

Редактор: `js/src/admin/editors/RaceEditor.tsx`; оформление:
`resources/catalog-editor.css`, классы `RpRaceEditor-*`. Проверки и нормализация:
`src/Catalog/Races/RaceCatalog.php`. Иконки полей берутся из общего
`resources/presentation/icons.json`.

Миграция `2026_10_17_000001_race_presentation.php` добавляет только три новых
столбца и не меняет существующие значения рас.
