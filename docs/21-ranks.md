# Ранги персонажа

Ранг назначает модератор через профиль активного персонажа: «Выдать» → «Ранг».
Выбери запись, укажи причину и нажми «Назначить ранг». Пункт «Без ранга» снимает назначение.
Новый персонаж создаётся без ранга. Характеристики и опыт не назначают ранг автоматически.

## Где редактировать

В админке появился раздел «Ранги». У записи есть название, еврейская буква, номер I–X,
описание и статус. Номер определяет порядок списка. Каждый номер может использоваться только один раз.
Описание отображается в подсказке и в окне назначения. Редактор использует общее окно шириной 480 пикселей.

Начальные десять записей находятся в `resources/defaults/ranks.php`:
א Алеф, ב Бет, ג Гимель, ד Далет, ה Хе, ו Вав, ז Заин, ח Хет, ט Тет, י Йод.
Файл нужен для первоначального наполнения. После установки редактируй записи в админке:
повторное наполнение сохраняет правки существующих записей.

Для нового форума после обычных миграций запусти `php packages/roleplay-new/tools/seed-ranks.php ID`.
Вместо `ID` укажи существующего администратора. Инструмент не создаёт аккаунты и не назначает ранги персонажам.
Подготовка тестовой копии вызывает наполнение автоматически.

## Как устроен код

- `src/Catalog/Ranks/RankCatalog.php` — проверка полей, единой шкалы и уникального номера.
- `src/Catalog/SeedRanks.php` — первоначальное наполнение с сохранением правок администратора.
- `src/Character/Moderation/CharacterRank.php` — план назначения или снятия ранга.
- `CharacterManagement` использует общую операцию персонажа: проверяет права и версии, сохраняет изменение и историю одной транзакцией.
- `js/src/admin/editors/RankEditor.tsx` — поля административного редактора.
- `js/src/forum/profile/CharacterManagementModal.tsx` — выбор и предпросмотр назначения.
- `js/src/common/character/RankLabel.tsx` — общее отображение буквы и названия в админке и анкете.
- `resources/ranks.css` — компактное оформление. Буква изолирована от русской строки, чтобы направление еврейского письма не переставляло текст.

Миграция добавляет только таблицу `roleplay_ranks` и nullable-ссылку `roleplay_characters.rank_id`.
Названия, буквы и иконки в миграции не задаются. Ранг не меняет игровые параметры.
Анкета читает актуальное название из справочника; история сохраняет название до и после действия на момент назначения.
`src/Character/Profile/CharacterProfile.php` явно возвращает `rank_id` и отображаемые поля `rank`:
внутренний снимок целиком в публичный API не передаётся. При добавлении поля персонажа проверь и этот список.

Выключенный ранг нельзя назначить заново, но он остаётся у получивших его персонажей.
Удаление используемого ранга запрещено; сначала сними или замени назначения.
Ранги поддерживают общий JSON-импорт и экспорт. Для обновления сохраняй поле `key`:
новый ключ с уже занятым номером считается конфликтом, а не переименованием.

## Проверки

`tests/check-ranks.php` проверяет начальную шкалу, права, назначение и снятие,
точный повтор команды, отображение выключенного ранга и историю, а также JSON-предпросмотр и применение.
Тест использует временные таблицы и не изменяет настоящих персонажей.
`tests/check-management-client.cjs` проверяет выбор ранга, сохранение и снятие через общий интерфейс выдачи.
Если сервер отклонил команду из-за изменившихся версий, окно показывает причину и кнопку «Обновить анкету».
Обновление заново получает права и варианты, сохраняя введённые данные; отклонённая команда автоматически не повторяется.
