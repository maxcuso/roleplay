# QuestPost Roleplay

A Flarum 2 extension developed for [QuestPost](https://questpost.ru), a text-based fantasy roleplaying community.

It brings character management and roleplaying mechanics directly into the forum.

## Features

- Character creation wizard with saved drafts and character sheets in user profiles.
- Attributes, skills, perks, spells, ranks, inventory and equipment.
- Character progression, experience, gold and automatic stat calculations.
- Spell learning from books and scrolls in a character's inventory.
- Events and quests with participant signup, episodes and reward distribution.
- Attribute and skill checks with automatic modifiers and dice rolls.
- Character review, moderation tools, notifications and character history.
- Configurable catalogs with JSON import and export.
- Built-in rules, world information and player guides.
