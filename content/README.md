## Как редактировать

- Меняй обычный текст прямо в Markdown-файлах. Заголовок `##` обозначает раздел, `###` — подраздел.
- Основа правил и мира — полные исходные тексты пользователя. Сохраняем авторские формулировки, подробности и BBCode; правим конкретные расхождения, не заменяем разделы пересказом.
- `<div>…</div>` служит для ориентирования при разметке, а не для удаления существующего оформления. У маркера `data-roleplay-block="experience-costs"` отдельное назначение: будущая вставка таблицы из админки.
- Объяснения для разработки и нерешённые вопросы храним в `planning`, чтобы они не попали в публичный текст.
- После изменения решения обновляем соответствующий текст и список вопросов. Старую формулировку не оставляем рядом как второе действующее правило.
- Полные описания сущностей в исходных текстах сохраняются до подключения динамических блоков. После подключения соответствующие списки и таблицы читаются из действующих справочников и настроек, без ручного дублирования значений.
- Правила, требующие изменения механики расширения, сначала согласуем отдельно. Лор сам по себе не включает автоматическое назначение рангов, учёт репутации или Дома в анкете.
