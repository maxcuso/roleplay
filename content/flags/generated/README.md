# Размер новых знамён

- Итоговый размер PNG: **1200 × 1600 px**.
- Соотношение ширины к высоте: **3:4**.
- Само полотнище занимает весь размер файла, без дополнительных внешних полей. Прозрачность остаётся только вне его формы — например, по бокам нижнего острия.
- Для поселений могут различаться нижние края полотнищ, при сопоставимой высоте и ширине.
- Полотнище и его фон приводятся к итоговому размеру отдельно от эмблемы. Саму эмблему не перерисовывать, не растягивать, не обрезать и не масштабировать; сохранять её пропорции и располагать по центру.

## Готовые файлы

Актуальные версии единого размера с полотнищем на весь файл находятся в `1200x1600-full/`:

- `nod-v1.png` — Нод.
- `grossblood-purple-v2.png` — текущая версия Гроссблад, без золотой обводки.
- `sylvanhart-v1.png` — Сильванхарт.
- `collegium-v4.png` — текущая Коллегия Магии: серебряная сова на золотой раскрытой книге, полумесяц, фиолетовое поле; щит по пользовательскому образцу со срезанными верхними углами, вертикальными боками, слегка скруглёнными нижними углами и коротким нижним остриём. Эмблема перенесена из v1 в исходном масштабе. `collegium-v3.png` и `collegium-v2.png` — предыдущие формы щита, `collegium-v1.png` — первоначальная версия с раздвоенным низом.
- `pantheon-v2.png` — текущий Пантеон Основ: уменьшенная золотая розетка из пяти равных лепестков вокруг серебряного круга, под ней две раскрытые серебряные ладони. Тёмно-красное поле; контур щита совпадает с `collegium-v4.png`, без городской короны. Пять лепестков обозначают пять богов и Основ, общий центр — единство веры. `pantheon-v1.png` — предыдущая версия без рук.
- `espada-v2.png` — Эспада; адаптированный череп, форма Грима с раздвоенным низом.
- `espada-v1.png` — предыдущая версия Эспады, близкая к исходному знаку.

Оригинальные изображения и промпты сохранены рядом с этим файлом. В актуальных версиях расширено полотнище и сделана однотонная заливка его фона; эмблемы перенесены из оригиналов в прежнем масштабе. Совпадение перенесённых пикселей проверено после сохранения PNG, изображения просмотрены.

Папка `1200x1600/` содержит прежний вариант с дополнительными прозрачными полями, включая предыдущую версию Гроссблад с золотой обводкой. Для дальнейшей работы использовать `1200x1600-full/`.

## Города

`cities-v1/` — первый набор из шести городских гербов на знамёнах: Квестпост, Верховье, Зеленолесье, Оазис Арах, Хиллсгард, Грим. Все файлы имеют размер 1200 × 1600 px; формы полотнищ соответствуют поселениям. Символика, список файлов и промпты описаны внутри папки.

## Варианты черепа Эспады для выбора

Файлы в `1200x1600-full/`, каждый 1200 × 1600 px:
